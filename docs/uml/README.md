# UML материалдары

- `images/` — архивтегі команданың бастапқы JPEG диаграммалары.
- `source/` — жобаның ағымдағы құрылымына сәйкестендірілген PlantUML бастапқы мәтіндері.
- `database-schema.md` — `DatabaseInitializer` кодынан алынған дерекқор кестелері мен байланыстары.

PlantUML бастапқы файлдарын PlantUML қолдайтын редакторда PNG/SVG ретінде экспорттауға болады. JPEG бастапқы диаграммалары автоматты түрде қайта жасалған жоқ.
