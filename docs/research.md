# Platonus — университеттің оқу процесін басқару жүйесі

## 1. Ұйым және жүйе сипаттамасы
Platonus — университеттің оқу процесін цифрлық түрде ұйымдастыруға арналған ақпараттық жүйе. Осы оқу жобасының мақсаты — студенттер, оқытушылар, оқу топтары, пәндер, сабақ кестесі, бағалар және сабаққа қатысу туралы ақпаратты бір консольдік Java қосымшасында басқару.

Жоба оқу мақсатында әзірленген жеңілдетілген модель болып табылады. Ол нақты Platonus өндірістік серверіне қосылмайды және университеттің ішкі деректерін пайдаланбайды.

## 2. Зерттелген бизнес-процестер
1. Әкімші студенттерді, оқытушыларды, топтарды және пәндерді тіркейді.
2. Оқу процесіне жауапты қызметкер пән, топ, оқытушы, күн, уақыт және аудитория бойынша сабақ жазбасын жасайды.
3. Оқытушы сабаққа қатысуды белгілейді.
4. Оқытушы студенттің пән бойынша бағасын енгізеді және жаңартады.
5. Жүйе бағалар бойынша орташа балл мен үлгерім статистикасын есептейді.
6. Есептер CSV және JSON форматтарына экспортталады.

## 3. Акторлар
| Актор | Міндеті |

| Әкімші | Студенттерді, оқытушыларды, топтарды және пәндерді басқару |

## 5. Функционалдық емес талаптар
- Java 17 және Maven қолданылуы.
- JDBC арқылы SQLite-пен қауіпсіз байланыс орнатылуы.
- SQL сұрауларында `PreparedStatement` қолданылуы.
- Негізгі бизнес логикасы модель, DAO, service және repository қабаттарына бөлінуі.
- JUnit 5 арқылы автоматтандырылған тесттер жазылуы.
- Құпия немесе нақты студенттік деректер қолданылмауы.

## 7. Жобаның шектеулері
Бұл нұсқа — оқу мақсатындағы консольдік прототип. Нақты Platonus серверімен интеграция, рөлдерге негізделген веб-аутентификация, REST API, күрделі өндірістік оңтайландыру (оқытушы жүктемесін теңестіру, аудитория сыйымдылығы, пәндердің апталық жиілігі) әзірге қарастырылмаған. Кесте генераторы — greedy эвристикасының оқу прототипі. `offline-attendance` ішкі демонстрациясы браузердің `localStorage` сақтауын пайдаланады және нақты серверге дерек жібермейді.
